Secure User Login System: Hash Table in C

A user registration and login system that stores accounts in an 11-bucket hash table using separate chaining. Source files:

  • hash_table.c: the hash table implementation (look-up, registration, password checking, file loading, memory clean-up)
  • hash_table.h: the User and HashTable structs and function declarations
  • main.c: a command-line program that loads users, registers a user and checks a password
  • users.txt: sample test accounts (made-up test data)

Build and run

gcc -Wall -o login main.c hash_table.c then ./login
